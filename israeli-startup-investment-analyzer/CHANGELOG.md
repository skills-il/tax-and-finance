# Changelog

All notable changes to this skill are documented here.

## [1.3.0] - 2026-09-15

### Fixed

- מועד ביטול צו ההצפנה תוקן לפי רשומות: הצו פורסם ב-20 בנובמבר 2025 ונכנס לתוקף ב-21 במרץ 2026, ולא במרץ 2025. רישיונות ותיקים עומדים בתוקפם עד תומם או עד שמונה חודשים מיום התחילה.
- הסקיל הורה להריץ סקריפט Python גם במארחים שאינם מריצים קוד (claude.ai, ChatGPT, Claude Desktop, Manus). נוספו נוסחאות חישוב ידניות.
- שני משפטים שחסרו בגרסה העברית נוספו.

### Added

- חוק האנג'לים בתוקף עד 31 בדצמבר 2026, והבהרה שסעיף 92א הוא הכרה בהפסד הון בהשקעה בהנפקה בבורסה ולא מסלול לסבב seed פרטי.
- חלון המס של הנחיית ה-SAFE המעודכנת (נחתם בין 1.1.2025 ל-31.12.2026, תקרה של 20 מיליון דולר).
- שאלות על נוסח ה-SAFE, זכויות המשקיע בתקנון, חשיפת מטבע, מילואים, סנקציות ודיווח לרשות החדשנות.

## [1.2.0] - 2026-08-09

### Added

- נוסף פרק "הבהרה משפטית" בראש הסקיל, הכולל גילוי שלמפעילי הכלי אין עניין אישי בנכסים הפיננסיים המוזכרים בו, ושהפלט אינו ייעוץ השקעות ואינו מביא בחשבון את מצבכם הכספי, את מטרות ההשקעה שלכם או את הסיכון שאתם יכולים לשאת.

### Changed

- התיאור נפתח כעת בהבהרה שהפלט אינו ייעוץ השקעות ואינו המלצה לקנות או למכור.
