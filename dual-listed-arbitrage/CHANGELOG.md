# Changelog

All notable changes to this skill are documented here.

## [1.2.0] - 2026-08-09

### Changed

- שם הסקיל עודכן ל"מעקב פערי מחיר ברישום כפול". השם הקודם כלל את המילה "ארביטראז'", שמתארת אסטרטגיית מסחר, בעוד שהסקיל רק מציג פערי מחיר בין שני רישומים של אותה מניה.
- התיאור נפתח כעת בהבהרה שהפלט אינו ייעוץ השקעות ואינו המלצה לקנות או למכור.

### Added

- נוסף פרק "הבהרה משפטית" בראש הסקיל, הכולל גילוי שלמפעילי הכלי אין עניין אישי בניירות הערך המוזכרים בו, ושהפלט אינו מהווה תחליף לייעוץ המתחשב בנתונים ובצרכים המיוחדים של כל אדם.
